# PIFE-Net

Physics-informed synthesis and evidence-calibrated fusion for abdominal MRI segmentation.

## Overview

PIFE-Net synthesizes auxiliary MRI contrasts from a single input sequence using a physics-constrained renderer and integrates them for segmentation.
